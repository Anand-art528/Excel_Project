# Retail Performance Analytics

## Project Overview

This project demonstrates the use of Microsoft Excel for retail business analysis and dashboard development. The dashboard provides key insights into sales performance, customer behavior, order trends, and product category performance, enabling data-driven decision-making.

## Objectives

* Analyze retail sales data to identify business trends.
* Monitor key performance indicators (KPIs).
* Evaluate customer purchasing behavior.
* Track sales performance across different categories and regions.
* Develop an interactive dashboard for business reporting.

## Tools & Techniques Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Cleaning & Transformation
* Dashboard Design

## Dashboard Features

* Total Sales Analysis
* Order Performance Tracking
* Category-wise Sales Analysis
* Customer Demographics Analysis
* Monthly Sales Trends
* Regional Performance Insights
* Interactive Filters and Slicers

## Key Insights

* Identified top-performing product categories.
* Analyzed monthly sales trends and seasonal patterns.
* Evaluated customer purchasing behavior.
* Compared regional sales performance.
* Highlighted business opportunities through visual analytics.
